# Data Structures & Algorithms in Java

Implementations of core data structures and algorithms in Java, written from scratch while learning DSA.

| Folder | What's inside |
|---|---|
| `Graph/` | BFS, DFS, all paths, cycle detection (directed and undirected), Dijkstra, Bellman-Ford, Disjoint Set |
| `Trees/`, `AVLTrees/` | Binary tree traversals, BST operations, AVL insertion with rotations |
| `LinkedList/` | Singly and doubly linked lists: insertion, deletion, reversal, recursion |
| `Stack/`, `Queue/` | Stack and queue implementations and problems |
| `searching/`, `sorting/` | Linear and binary search; classic sorting algorithms |
| `Recursion/` | Recursion problems and patterns |
| `Patterns/`, `Math functions/` | Pattern printing, HCF, LCM and other number problems |
